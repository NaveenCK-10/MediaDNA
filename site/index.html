SCIENTIFIC CONTEXT

Ranking ≠ Thresholded Classification

The reported locked-test ROC-AUC captures ranking discrimination. At the historical operating point, the same evaluation produced zero specificity and MCC = 0, so the thresholded behavior must be reported separately rather than converted into an "accuracy" claim.
